## `SYNC_CODE` — 아이폰·맥북 데이터를 연결하는 암호

`SYNC_CODE`는 아이폰과 맥북이 "같은 사람의 같은 데이터"라는 걸 서버가 알아볼 수 있게
해주는 일종의 암호예요. 직접 정하시면 됩니다. 예: `suhee-sync-2026` 처럼 알파벳/숫자를
섞은, 남이 쉽게 추측하기 어려운 문자열을 추천해요. 특별한 규칙은 없고, 딱 하나만
지키면 돼요 — **모든 기기에 완전히 동일하게 입력**해야 한다는 것.

1. Netlify 환경변수에 `SYNC_CODE`를 원하는 값으로 추가하고 재배포합니다.
2. 아이폰에서 앱을 열고 오른쪽 위 🔄 버튼을 눌러 "기기 연결" 화면을 엽니다.
3. 방금 정한 코드를 입력하고 "연결하기"를 누릅니다.
4. 맥북에서도 같은 주소로 접속해서 🔄 버튼을 누르고, **똑같은 코드**를 입력해 연결합니다.
5. 이제 두 기기 중 한쪽에서 일정/할일/읽을거리를 추가·수정·삭제하면, 앱이 켜져 있는
   다른 기기에도 자동으로 반영돼요. (약 25초 간격으로 서버를 확인하고, 앱을 다시 열거나
   화면을 다시 볼 때도 즉시 한 번 더 확인합니다.)

### 알아두면 좋은 점

- 완전히 실시간(0초)은 아니고, 최대 약 25초 정도 반영에 시간이 걸릴 수 있어요.
- 두 기기에서 "동시에" 같은 항목을 수정하면, 더 나중에 저장된 쪽이 최종 반영돼요
  (더 오래된 수정 내용은 덮어써질 수 있어요).
- `SYNC_CODE`는 비밀번호이긴 하지만 정식 로그인 시스템처럼 강력하진 않아요. 이 코드를
  아는 사람은 누구나 내 일정 데이터를 볼 수 있으니, 남과 공유하지 않는 문자열로
  정해주세요.
- 기기 연결을 끊고 싶으면 🔄 화면에서 "연결 해제"를 누르면 돼요. 이후에는 그 기기의
  변경사항이 더 이상 다른 기기와 동기화되지 않고, 그 기기에만 저장돼요.

## 배포 후 알림 확인하는 방법

1. 아이폰에서 배포된 주소로 접속 → 홈 화면에 추가.
2. 앱 실행 → 오른쪽 위 🔔 버튼 → "알림 켜기" → iOS 알림 권한 허용.
   (알림을 켜려면 먼저 🔄 화면에서 `SYNC_CODE`로 기기 연결이 되어 있어야 해요.)
3. 같은 화면에서 "테스트 알림 보내기"를 눌러 실제로 알림이 오는지 확인.
4. 정상 동작하면 일정/읽을거리를 추가할 때 "🔔 이 날짜·시간에 알림 받기"를 켜서 사용하세요.

알림은 최대 5분 단위로 확인해서 발송되므로, 설정한 시간과 실제 도착 시간 사이에
몇 분 정도 오차가 있을 수 있어요.
